# Fichas del Juego

Coloca aquí las imágenes de las fichas con estos nombres exactos:

## Nombres requeridos:
- `ficha-circle.svg` (o .png) - Ficha circular
- `ficha-diamond.svg` (o .png) - Ficha diamante  
- `ficha-star.svg` (o .png) - Ficha estrella
- `ficha-triangle.svg` (o .png) - Ficha triángulo
- `ficha-hex.svg` (o .png) - Ficha hexágono

## Especificaciones:
- **Formato**: SVG preferido, PNG como alternativa
- **Dimensiones**: 256x256 o 512x512 (cuadrado)
- **Fondo**: Transparente
- **Peso**: ≤ 100 KB por archivo

Una vez colocadas aquí, se integrarán automáticamente al juego.
