# Iconos del Juego

Coloca aquí los iconos e imágenes del juego:

## Iconos requeridos:
- `casita.svg` (o .png) - Icono para propiedades compradas
- `mejora.svg` (o .png) - Icono para mejoras de propiedades  
- `monopolio.svg` (o .png) - Icono para monopolios (opcional)

## Especificaciones:
- **Formato**: SVG preferido, PNG como alternativa
- **Tamaño**: 64x64 o 128x128 píxeles (cuadrado)
- **Fondo**: Transparente
- **Estilo**: Simple, reconocible a tamaño pequeño

Una vez colocados, se integrarán automáticamente al tablero.
